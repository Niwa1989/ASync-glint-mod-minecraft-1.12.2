# ASync-glint-mod-minecraft-1.12.2
ASync_glint — клиентский мод для Minecraft Forge 1.12.2, заменяющий стандартный фиолетовый блеск зачарованной брони на настраиваемый эффект

Возможности:
- Выбор цвета: синий, голубой, белый, золотой, красный, зелёный, фиолетовый и радужный
- Полное отключение блеска
- Настройка прозрачности от 25% до 100% с шагом 1%
- Сохранение параметров после перезапуска Minecraft
- Управление через «Настройки → Внешний вид»
- Оптимизированный однопроходный рендер
- Отключение эффекта на игроках дальше 64 блоков для повышения FPS

Мод использует Coremod/ASM-трансформер для изменения стандартного рендера зачарованной брони. Возможны конфликты с другими модами, изменяющими LayerArmorBase.renderEnchantedGlint
